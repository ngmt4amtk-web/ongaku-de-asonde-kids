# おんがくで あそんでみた（子ども版）

小学校の低学年から中学年の子が、音楽の知識がなくても、遊びながら1曲作れるページです。パソコンのブラウザで `index.html` を1つ開くだけで動きます。インストールは要りません。

## あそびかた（子ども向け）

1. 「はじめる」をおす。
2. きぶんを えらぶ（あかるい・やさしい・せつない・くらい・ふしぎ・かっこいい）。まよったら「おまかせ」。
3. 「きいてみる」で、ばんそうを きく。「この ばんそうで メロディを つくる」をおす。
4. マスを おして、音を おく。おなじ マスを もう一回 おすと きえる。まよったら「おまかせメロディ」。
5. 音を 4つ おいたら「できた！」。「さいせい」で きける。「とっておく」で この きかいに のこせる。

まちがえても「ひとつ もどす」で もどせます。「やりなおす」で ぜんぶ けせます。

## 大人の方へ

### 開き方

- パソコン: `index.html` をダブルクリックして、ブラウザで開きます。Mac の Chrome で、ダブルクリックと同じ開き方（file://）で最後まで動くことを確かめました。Safari と Edge では確かめていません。
- iPad・iPhone: ファイルアプリで `index.html` を押すと、中身を見るだけの画面（クイックルック）で開くため、このページは動かない見込みです（実機では確かめていません）。iPad で使うには、ページをWebに置いて Safari で開く必要があります。Webに置く（公開する）かどうかは、本人の確認を取ってから決めます。
- iPhone・iPad の Safari では、消音モードの間はページの音が鳴らないことがあります。音が出ない時は消音モードを切ってください。
- 音は、最初にボタンを押した時から鳴ります（ブラウザの決まりで、押す前は鳴らせません）。

### 2つのあそびかた

- かんたん（最初はこちら）: 伴奏はきぶんで決まります。音の長さは全部1拍です。
- じっくり: 4つの小節（へや）それぞれの和音を、候補から選べます。音の長さも1拍・2拍・4拍から選べます。
- どちらでも、「やすみ」で休符を置けます。

### 言葉と見せ方の工夫

- 「コード」は「和音」、「BPM」は「テンポ（ゆっくり・ふつう・はやい）」と言いかえています。和音・小節・拍・伴奏・曲には、ふりがなを付けています。和音・小節・拍・伴奏・テンポには、初めて出る所で身近なたとえを添えています（和音＝いくつかの音をいっしょに鳴らした響き、小節＝曲の1つのへや、拍＝手拍子1回分、伴奏＝歌のうしろで鳴る音、テンポ＝曲の速さ）。
- 音の高さは、上下の矢印と虹色の段で見せます。ドレミやコード名（C、Am など）は、右上の「おとなの まめちしき」を押した時だけ小さく出ます。
- 使う音は、きぶんごとに、どれを置いても外れにくい8つの音にしぼっています。
- 1画面でやることは1つにしています。上の4つの丸で、いまどこにいるかが分かります。

### 参考ページから変えたこと

参考にしたページ（音楽で遊んでみた）の機能を、子ども向けに作り直しました。参考ページのソースコードは使っていません。画面と流れだけを参考にして、一から書いています。

- 曲の名前を付ける: 外した。題は「☀️ あかるい 曲 #3」のように自動で付く。名前の入力欄を置くと、子どもが自分の名前を書くおそれがあるため。
- 共有リンクを作る: 外した。曲のデータが外へ出るため。
- X（旧Twitter）への紹介文: 外した。SNSへの投稿は子ども版の対象外のため。
- MIDIで保存: WAV（音のファイル）での保存に変えた。MIDIはそのままでは子どもが聴けないため。WAVは端末に保存され、ふつうの音楽のように再生できる。
- 0.5拍の音: 外した（1・2・4拍のみ）。マスが細かくなり、指で押しにくくなるため。
- コード名・ドレミの常時表示: スイッチで出す形にした。知識がない子でも迷わないようにするため。
- 曲の長さの選択: 4小節だけにした。1〜2分で「できた！」まで行けるようにするため。
- テンポ（BPMの数値）: 「ゆっくり・ふつう・はやい」の3択にした（数字は小さく添える）。数字より、たとえの方が分かりやすいため。

### 安全の決まり

- 名前・年齢・メールなど、文字を書き込む欄は1つもありません。
- 外への通信をしません。ページの中に Content-Security-Policy（ブラウザに「外と通信しない」と伝える設定）を入れ、外部への接続・外部ファイルの読み込みを止めています。フォント・画像・音のライブラリも外から読みません。音はブラウザの標準機能（Web Audio API）でその場で作っています。
- 共有リンク、SNSへの投稿、広告、課金、外部サイトへのリンクはありません。
- 作った曲は、その端末のブラウザの中（localStorage）にだけ保存します（最大10曲。それを超えると古い曲から消えます）。ブラウザの履歴やデータを消すと、保存した曲も消えます。
- 「音の ファイルに する」は、曲をWAVファイルにして、その端末に保存するだけです。どこにも送りません。
